🧠 Continual Learning: Concepts That Evolve

A research direction exploring a more realistic version of continual learning:

Traditional:
A → B → C → D

Real World:
A → B → C → A' → B' → C' → A''
          ↳ concepts change over time

Research question:

Can an AI system learn recurring concepts that evolve over time without catastrophic forgetting?
